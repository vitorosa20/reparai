# Guia Rápido: Rodando o Projeto Reparaí

### Requisito
É necessário um Mac com **Xcode** instalado.

### 1. Clonar o Projeto
Abra o aplicativo Terminal e execute o comando:

```bash
git clone [https://github.com/paulolazarini/reparai.git](https://github.com/paulolazarini/reparai.git)
```

### 2. Abrir no Xcode
Na pasta reparai que foi criada, abra o arquivo Reparai.xcodeproj.

### 3. Aguardar Dependências
Espere o Xcode baixar os pacotes do Swift. A barra de status no topo da janela indicará o progresso.

### 4. Rodar o App
Escolha um simulador de iPhone na barra superior e clique no botão de Play ou use o atalho Cmd + R.

O simulador será iniciado e o aplicativo Reparaí irá rodar.
